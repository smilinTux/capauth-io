🎯 What is CapAuth?

Stop giving corporations control over your identity.

CapAuth replaces corporate login systems with cryptographic sovereignty. Your PGP key becomes your identity. You issue capability tokens for granular access control. Your data stays where you choose.


No more "Sign in with Google." No more OAuth dependency. No more platform lock-in.

Just you, your keys, and complete control.

Feature Traditional Auth CapAuth
Identity Email/phone they own PGP key you own
Access Role-based ("Admin") Capability-based ("Read:name only")
Delegation Admin grants permissions You issue per-relationship tokens
Data Storage Stored on their server Stored where you choose
Revocation They revoke access You revoke tokens

✨ Key Features

Sovereign identity meets granular access control.

🔑 PGP Root Identity

Your PGP public key is your identity. Self-issued, self-sovereign. No corporation can revoke it.

🎯 Capability Tokens

Issue granular permissions per relationship. Henry gets your name, George gets your full profile.

🏠 Storage Choice

Local database, encrypted cloud, IPFS — you choose where your data lives. Not them.

⚡ Instant Revocation

Revoke access instantly by invalidating tokens. No waiting for "account deletion" processes.

🔗 Delegation Chains

Delegate tokens with limited scope and expiration. Perfect for temporary access or agent systems.

🛡️ SK Jail Reputation

Community-based trust system. Bad actors get isolated while maintaining privacy.

🏗️ How it Works

Simple concepts, powerful results.

Architecture Overview

User A (PGP Key)        Registry          User B (PGP Key)
    │                        │                    │
    ├─ Register ────────────→│                    │
    │  (pubkey + pointer)    │                    │
    │                        │                    │
    ├────── Issue CapToken ──│───────→│          │
    │  (caps: ["read:name"]) │   (stored token)  │
    │                        │                    │
    │                        │← Request data ─────┤
    │←── Serve filtered ─────│   (with token)     │
       profile (name only)   │                    │

Core Process

  1. Register: Your PGP public key + data storage pointer goes in the registry
  2. Issue: Create capability tokens for specific relationships and permissions
  3. Access: Others use your tokens to access exactly what you authorized
  4. Control: Revoke, modify, or expire tokens at any time

🚀 Get Started

Ready to own your identity? Here's how to begin:


# Install CapAuth CLI
npm install -g capauth

# Initialize your sovereign identity
capauth init

# Register with the network
capauth register
